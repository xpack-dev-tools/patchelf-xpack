# The xPack NixOS PatchELF

A standalone, cross-platform (macOS, GNU/Linux) binary
distribution of NixOS PatchELF,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project web site](https://xpack-dev-tools.github.io/patchelf-xpack/).

## Project source

The source code of the current release is available on
[GitHub tag v0.18.0-1.1 tree](https://github.com/xpack-dev-tools/patchelf-xpack/tree/v0.18.0-1.1).
